# Build log — 2026-09-18

First entry in the daily build archive.

## Shipped
- Imported the full working source of the SaaS live dashboard into this repository.
- Established the archive layout: `artifacts/` (web app + API server), `lib/`
  (API spec, generated clients, database), `scripts/`, `docs/`.
- Added `.env.example` covering every environment variable the app requires
  (`DATABASE_URL`, `PORT`, `BASE_PATH`, Clerk keys, `LOG_LEVEL`).
- Added `README.md` (what the app does, stack, how to run it) and
  `docs/architecture.md` (request path, package roles, derived values).

## State of the app
- Public landing page plus seven authenticated routes: dashboard, habits, money,
  health, growth, goals, calendar.
- API covers all seven areas, with per-user seeding on first authenticated use
  and Zod-validated responses generated from `openapi.yaml`.
- Postgres schema defined in Drizzle across nine `mindflow_` tables.

## Decisions
- The archive mirrors the working monorepo layout rather than renaming folders,
  so a commit here can be diffed directly against the live workspace.
- Orval-generated code (`lib/api-client-react/src/generated/`,
  `lib/api-zod/src/generated/`) is left out of the archive; it is regenerated
  from the spec with one command and would otherwise add churn to every diff.
- The secondary product-deck and mockup-sandbox workspaces are out of scope for
  this repository, which tracks the dashboard application only.
- Only the shadcn/ui components the app actually imports are vendored (button,
  card, input, progress, skeleton, toast, toaster, use-toast, badge). The rest of
  the unused shadcn set is left out; `components.json` is committed, so any other
  component can be added back with `pnpm dlx shadcn@latest add <name>`.

## Known issues
- Typecheck fails on a fresh clone until the codegen step has been run once.
- The health page's circular progress ring is a CSS stand-in rather than a real
  SVG arc, so it does not visually reflect partial progress.
- Habit completion is a toggle without a per-day record, so streak counts can
  drift if a habit is toggled repeatedly in one day.
